## 🚀 How to Use

### Run the Seeder
```bash
# Fresh database with seeder
php artisan migrate:fresh --seed

# Seed only
php artisan db:seed --class=BlogSeeder

# Force refresh
php artisan db:seed --class=BlogSeeder --force
```

### View the Content
1. Navigate to `/blogs` to see the blog index
2. Click on any published post to view full content
3. Check the draft post in the admin panel
4. Verify all components render correctly

### Customize
1. Edit `database/seeders/BlogSeeder.php`
2. Modify content, categories, or components
3. Run the seeder again with `--force` flag

## 📞 Support

### Common Tasks

**Add a new post:**
```php
[
    'title' => 'Your Title',
    'slug' => 'your-slug',
    'category_id' => $categories['category-key'],
    'content_json' => [
        $this->block('heading', 'heading', 'Title', ['level' => 1, 'text' => 'Your Title']),
        // Add more blocks...
    ],
    'status' => 'published',
    'published_at' => now(),
],
```

**Modify existing post:**
1. Edit the post array in the seeder
2. Run `php artisan db:seed --class=BlogSeeder --force`

**Add new category:**
```php
['name' => 'Category Name', 'slug' => 'category-slug', 'description' => 'Description']
```
